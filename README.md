# Chat Input Helper

「パズルアンドサバイバル」のチャット欄で使える文字装飾を、少し楽にするための補助ツールです。

iPhoneのブラウザから利用できます。

> チャットの内容をどこかに収集・保存する仕組みは使用していません。
>
> iPhoneでのみ動作確認しています。

---

## 概要

このツールでは、チャットに入力する文字に対して、

- 色付け
- 上付き文字
- 下付き文字
- 1文字ずつのランダムカラー
- 1文字ずつの上付き・下付き
- ランダムカラー＋上付き・下付き

などの装飾を、ボタン操作で簡単に行えます。

装飾した文字列をコピーして、ゲームのチャット欄などに貼り付けて使用します。

---

## 使い方

1. 「テキスト入力」欄に文章を入力します。
2. 装飾したい文字を選択します。
3. 使用したい装飾ボタンを押します。
4. 「プレビュー」で表示を確認します。
5. 「copy」を押して文字列をクリップボードへコピーします。
6. ゲームのチャット欄などへ貼り付けます。

---

## ボタンの説明

### カラーボタン

以下の色を選択できます。

- 白
- 灰
- 青
- 赤
- 緑
- 黄
- 紫
- 水
- 桃
- 橙

選択範囲に色の装飾を追加します。

### up

選択範囲を上付き文字にします。

### up off

上付き状態を終了するタグを入力します。

### dn

選択範囲を下付き文字にします。

### dn off

下付き状態を終了するタグを入力します。

### random

選択範囲の文字を、1文字ずつランダムな色にします。
