Chat Input Helper

About This Tool

Chat Input Helper is a small utility that makes it easier to add text formatting to messages in the chat of Puzzles & Survival.

You can add colors, apply gradients or random colors to selected text, and use formatting such as superscript, subscript, strikethrough, and underline.

You can also insert kaomoji (Japanese-style text emoticons) and save or reuse frequently used messages.

The tool is designed to keep things simple and easy to use, especially on an iPhone.

Privacy

This tool does not send your chat text to a server or collect and store it remotely.

Saved messages and color settings are generally stored in your browser on the device you are using.

Getting Started

First, enter your text in the Text Input field near the top of the tool.

To format only part of your text, select the text using your iPhone's usual text-selection controls, then tap the button for the effect you want.

Select Text → Apply Formatting
You can apply colors, superscript, subscript, strikethrough, underline, and other effects to the selected text.

If no text is selected when you tap a formatting button, the operation applies to the entire contents of the input field.

For the best results, select the text first, then tap the formatting button when you want to format only part of your message.

Color buttons work differently: they insert a color code at the current cursor position instead of replacing the text.

Tap the text field and place the cursor where you want the color code to be inserted.

Save or Reset Color Settings

Color Settings
Set your custom color and the start and end colors used for gradients.
Save Color Settings
Saves your current custom color and gradient start and end colors in the browser on this device.
Reset Color Settings
Resets the saved color settings to their default values.

This is useful if you want to keep the colors you use most often.

Saved settings are generally managed locally in your browser on this device.

Text Selection and Formatting Buttons

These buttons apply formatting or color effects to the text you want to modify.

If text is selected, the selected range is used.

If no text is selected, the entire input field is used.

The buttons are arranged in a horizontal row. If they do not all fit on the screen, swipe left or right to find the button you need.

gradation

rainbow

The rainbow effect uses your current custom color as its starting reference and varies the hue from there.

random

Copy

Copy
Copies the complete text in the input field to your clipboard.

You can then paste the copied text into the game's chat or another app.

When copying succeeds, the cat inside the button briefly grows larger.

Undo

Undo
Reverses the most recent editing action performed by this tool.

The tool keeps up to 50 editing-history entries.

Undo can reverse tool actions such as inserting color codes, applying formatting, clearing the text field, and inserting a saved message.

When text was selected before formatting, Undo also restores the previous selection when possible.

Clear

Clear
Deletes all text from the input field.

Clearing the text can also be undone.

If you clear the field by mistake, tap Undo to restore the previous contents.

Saved Messages

Save messages you use often and insert them whenever you need them.

Saved Message A
A slot for saving and inserting Message A.
Saved Message B
A slot for saving and inserting Message B.
Saved Message C
A slot for saving and inserting Message C.

When you insert a saved message, it replaces the current contents of the input field.

It is not added to the end of your current text; the entire input field is replaced.

Saved messages are stored in your browser on this device.

The messages you save are not sent from this tool to a server.

If you clear your browser data, or if your browser settings remove stored data, your saved messages may be lost.

Preview

Preview
Interprets the formatting tags in the input field and displays the result in a way that resembles the game's chat display.

Use the preview while editing to check how colors, superscript, subscript, strikethrough, underline, and other formatting may appear.

When S and U overlap
If strikethrough and underline are applied to the same text, the preview gives priority to strikethrough.

Using the Tool on a Smartphone

This tool is designed with iPhone text selection and formatting in mind.

Instead of shrinking buttons until they become difficult to tap, the tool lets you scroll horizontally when the buttons do not fit on the screen.

For example, the formatting buttons appear in a row like this:

Depending on how your iPhone handles text selection, the selection may disappear when you tap a button.

Undo is designed to restore the previous selection when possible.
