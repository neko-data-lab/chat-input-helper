Chat Input Helper

このツールについて

Chat Input Helperは、 「パズルアンドサバイバル」のチャット欄で使える 文字装飾を、少し楽にするための補助ツールです。

文字に色を付けたり、 選択した文字をグラデーションやランダムカラーにしたり、 上付き・下付き・取り消し線・下線などの装飾を加えたりできます。

難しい操作はできるだけ減らして、 iPhoneから気軽に使えるように作っています。

プライバシーについて

このツールに入力したチャット内容を、 サーバーなどへ送信して収集・保存する仕組みはありません。

定型文などの設定も、基本的にこの端末のブラウザ内に保存されます。

基本的な使い方

まず、画面上部の 「テキスト入力」欄に文字を入力します。

文字の一部だけを装飾したい場合は、 iPhoneの通常の操作で文字を選択してから、 目的のボタンを押してください。

たとえば、

文字を選択 → 色を選ぶ
選択した文字の位置にカラーコードを追加できます。

範囲選択に対応した装飾ボタンでは、 選択した文字をまとめて装飾できます。

テキスト入力欄をタップしてカーソルを置けば、 その位置にカラーコードなどを追加することもできます。

カラーボタン

カラーボタンは、 文字に色を付けるためのカラーコードを カーソル位置へ追加するボタンです。

それぞれ決められた色のカラーコードを、 カーソル位置へ追加します。
カスタム
自分で設定したカスタムカラーの カラーコードをカーソル位置へ追加します。

カラーボタンを押すと、 カラーコードを追加したあと、 カーソルは自動的に1文字分右へ移動します。

そのため、 続けて別の色を追加したり、 そのまま文字を入力したりできます。

カラーボタンは文字そのものを置き換えるのではなく、 現在のカーソル位置へカラーコードを追加する仕組みです。

カラー設定保存・リセット

カラー設定保存
現在設定しているカラー関連の設定を、 この端末のブラウザに保存します。
カラー設定リセット
保存しているカラー設定をリセットし、 初期状態に戻します。

よく使う色の設定を残しておきたい場合に便利です。

保存された設定は、基本的にこの端末のブラウザ内で管理されます。

文字を選択してから使うことを想定した 装飾・カラー操作のボタンです。

ボタンが横一列に並んでいるため、 画面の幅に収まらない場合は 左右へスワイプして目的のボタンを表示してください。

up
選択した文字を上付き文字にします。
dn
選択した文字を下付き文字にします。
S
選択した文字を取り消し線で装飾します。
U
選択した文字に下線を付けます。
SとUを重ねた場合
SとUの装飾範囲が重なった場合、 プレビューでは取り消し線を優先して表示します。
gradation
選択した文字を1文字ずつ異なる色にし、 設定した色を起点とした同系色のグラデーションにします。
rainbow
選択した文字の色相を少しずつ変化させ、 虹色のようなグラデーションにします。
random
選択した文字を1文字ずつ ランダムな色にします。
up/dn
選択した文字を1文字ずつ、 上付き・下付き・上付き・下付き…… というように交互にします。
rnd+up/dn
文字を1文字ずつランダムな色にしながら、 上付き・下付きを交互にします。
範囲選択系ボタンを使うときは、 先に装飾したい文字を選択しておくのがおすすめです。

copy

copy
入力欄に入っている完成した文字列を クリップボードへコピーします。

コピーした文字列を、 ゲームのチャット欄などへ貼り付けて使用できます。

コピーが成功すると、 ボタン内の猫が一瞬少し大きくなります。

undo

undo
直前の編集操作を取り消します。

最大50回分まで編集履歴を保持します。

文字を選択して装飾した場合は、 可能な範囲で装飾前の選択範囲も復元します。

そのため、

文字を選択
↓
装飾する
↓
undo
↓
別の装飾を試す

という使い方もしやすくなっています。

clear

clear
入力欄の文字をすべて消去します。

clearによる削除もUndoの対象です。

間違えて消してしまった場合は、 undoで直前の状態へ戻すことができます。

定型文

よく使う文章を保存しておき、 必要なときに呼び出せる機能です。

定型文A
定型文Aを保存・呼び出しするためのスロットです。
定型文B
定型文Bを保存・呼び出しするためのスロットです。
定型文C
定型文Cを保存・呼び出しするためのスロットです。

定型文は、 この端末のブラウザ内に保存されます。

そのため、 定型文として保存した文章が このツールからサーバーへ送信されることはありません。

ブラウザのデータを削除した場合や、 ブラウザ側の設定などによって保存データが消去された場合は、 保存していた定型文も失われる可能性があります。

プレビュー

プレビュー
入力欄に入力されている装飾用タグを解析し、 実際のチャット画面に近い形で表示します。

色や上付き・下付き・取り消し線・下線などが どのように表示されるかを確認しながら編集できます。

SとUが重なった場合
取り消し線と下線が同じ文字に重なっている場合、 プレビューでは取り消し線を優先して表示します。

スマートフォンでの操作

このツールは、 iPhoneで文字を選択して装飾する使い方を 特に意識して作っています。

画面の幅に入りきらない操作ボタンは、 無理に小さくするのではなく、 横方向へスクロールして使えるようにしています。

たとえば範囲選択系のボタンは、

up
dn
S
U
gradation
rainbow
random
up/dn
rnd+up/dn

この列を左右へスワイプすると、 隠れているボタンを表示できます。

文字を選択した状態でボタンを押すと、 iPhone側の動作によって選択範囲が解除されることがあります。 このツールでは、 undoを使ったときに可能な限り 操作前の選択範囲を復元するようにしています。
