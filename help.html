Chat Input Helper ― 使い方

このツールは、 「パズルアンドサバイバル」の チャット欄で使える装飾を 楽にしてくれるかもしれないツールです。

チャットの内容がどこかに収集される なんてことはないので安心してください ヽ(=´▽`=)ﾉ

iPhoneでのみ動作確認しています。

概要

このツールでは、チャットに入力する文字に対して、 色付け・上付き・下付きなどの装飾を 簡単なボタン操作で行うことができます。

装飾した文字列を最後にコピーして、 ゲームのチャット欄などに貼り付けて使用してください。

使い方

まず、上部の「テキスト入力」欄に チャットへ入力したい文章を入力します。

文字の一部分だけを装飾したい場合は、 入力欄の中で装飾したい文字を選択してから 各ボタンを押してください。

  • 白 / 灰 / 青 などのカラーボタンを押すと、 選択範囲にその色の装飾を追加します。
  • up 選択範囲を上付き文字にします。
  • up off 上付き状態を終了するタグを 入力します。
  • dn 選択範囲を下付き文字にします。
  • dn off 下付き状態を終了するタグを 入力します。
  • random 選択範囲の文字を、 1文字ずつランダムな色にします。
  • up/dn 選択範囲を、 上付き・下付き・上付き・下付き…… と1文字ずつ交互にします。
  • rnd+up/dn 1文字ずつランダムな色にしながら、 上付き・下付きを交互に設定します。
  • undo 直前の操作を取り消します。 複数回押すことで、 保存されている範囲まで順番に戻すことができます。
  • copy 装飾後の文字列をクリップボードへ コピーします。
  • clear テキスト入力欄をすべて消去します。 消去後に undo を押すと、 消去前の状態に戻せます。
※ 装飾の結果は「プレビュー」で確認できます。
※ ゲーム側の仕様変更などにより、 以前と同じように表示されなくなる場合があります。

ツールの仕様

このページに記載している内容および このツールの仕様は、 2026年9月30日時点 の情報をもとにしています。

  • iPhoneで動作確認しています。
  • Android端末など、 iPhone以外の環境では 動作確認を行っていません。
  • 入力した文章は、 このツールから外部のサーバーへ 送信・保存する仕組みを 使用していません。
  • プレビューは、 入力した内容を端末上で処理して 表示しています。
  • Undo履歴は、 ページを閉じたり再読み込みしたりすると 消えます。
  • Undo履歴は最大50段階までです。

終わりに

このツールは、 チャットの文字装飾をちょっと楽にするための 個人的な補助ツールです。

ゲームや端末、ブラウザなどの環境によっては、 意図した表示にならない場合があります。

また、このツールを使用したことによって 発生した問題や不具合などについては、 作者では責任を負いかねますので、 あらかじめご了承ください。
